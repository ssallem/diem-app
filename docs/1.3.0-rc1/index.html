Diem 1.3.0 — 스토어 업데이트 전 확인 요청

결론 먼저: 이번 버전은 "종이" 프리셋 3종(만세력·줄공책·승차권)과 각각의 다크 모드를 더하고, 상세 화면까지 같은 종이로 입힌 디자인 업데이트입니다. 기능·데이터 구조는 1.2.1과 같습니다. 아래 APK로 실기기에서 보시고, 승인해 주시면 Play 내부 테스트 → 프로덕션 순서로 올리겠습니다.

릴리스 APK는 스토어에서 설치한 Diem 위에 덮어 설치되지 않습니다. 스토어 설치본은 Google Play 앱 서명 키로, 이 파일은 업로드 키로 서명돼 있어 "앱이 설치되지 않았습니다"가 뜹니다. 스토어 앱을 지우고 깔면 그 폰의 기념일 데이터가 사라지니, 스토어 앱이 있는 폰에서는 Dev 빌드로 확인해 주세요.

설치 순서

  1. 위 링크를 폰에서 탭

    Chrome이 "이 유형의 파일은 기기에 해를 끼칠 수 있습니다"라고 물으면 다운로드.

  2. 다운로드한 APK 열기

    알림 또는 파일 앱에서 탭. "출처를 알 수 없는 앱 설치 허용"을 물으면 Chrome(또는 파일 앱)에 대해 허용.

  3. 설치 → 홈 화면의 "Diem Dev"

    기존 Diem 아이콘은 그대로 남습니다. 다 보신 뒤 Dev 앱은 일반 앱처럼 삭제하면 됩니다.

보시기 전에 — 주의사항 2가지

① "테스트 광고"라고 적힌 광고가 보입니다. 목록 중간의 네이티브 카드와 상세 화면 하단 배너입니다. 이번 빌드는 광고 모듈이 켜져 있고 단위 ID는 Google 테스트 ID입니다. 실제 출시본에 광고를 넣을지, 넣는다면 실제 AdMob ID로 바꿀지는 출시 전에 따로 결정할 항목이라 이번 확인 대상이 아닙니다.

② 상세 화면의 "AI 도구함 › 축하 멘트"는 열리지만 생성은 실패합니다. AI 백엔드(프록시 서버)를 아직 배포하지 않았습니다. 출시본은 백엔드 주소가 비어 있으면 이 메뉴 자체를 숨기므로, 스토어에는 보이지 않습니다. 이것도 이번 확인 대상이 아닙니다.

확인해 주실 것

테마 전환은 목록 화면의 톱니(줄공책에서는 왼쪽 위 놋쇠 단추) › 테마 시트에서 합니다.

항목보는 곳
1종이 프리셋 3종이 각각 "물건"처럼 읽히는지만세력 = 가죽 표지 위 종이, 줄공책 = 노란 괘선지 + 바인더, 승차권 = 크라프트 위 인쇄 티켓테마 › 색상
2줄공책의 제목·숫자가 잘 읽히는지매직 포스터체(Do Hyeon). 이전 손글씨체 4종은 실기기에서 읽기 어려워 탈락했습니다. 본문은 활자(Pretendard)입니다.줄공책 목록·상세
3상세 화면도 같은 종이인지줄공책: 바인더 바(뒤로·편집·삭제) + 괘선 위 정보, 사진은 붙인 인화지. 승차권: 그 기념일의 티켓 한 장(번호·바코드).기념일 탭
4다크 모드 3종"조명을 끈 같은 종이" — 종이만 어두워지고 빨간 펜·잉크는 살아 있어야 합니다.테마 › 화면 모드 › 다크
5테마 시트가 끝까지 열리는지"화면 모드"와 "언어"가 폰 아래 내비게이션 바에 가리지 않아야 합니다(수정한 결함).테마 시트
6기존 기능 회귀 없음기념일 추가·편집·삭제, 고정(핀), 캘린더에 추가, 위젯 3종, 알림 — 1.2.1과 동일해야 합니다.전체

막히거나 어색한 점은 화면 캡처 + 어느 프리셋/어느 화면만 알려주시면 됩니다. 이 페이지 하단의 캡처와 같은 화면이 나오면 정상입니다.

화면 — 실기기 캡처

Galaxy S24+ · Dev 빌드 · 샘플 데이터. 왼쪽 목록, 오른쪽 상세.

1.2.1 → 1.3.0 변경 요약

  • 종이 프리셋 3종 — 만세력(Almanac)·줄공책(Legal Pad)·승차권(Ticket). 색뿐 아니라 서체·목록 구조·상세 화면까지 프리셋이 정합니다. 기존 색 프리셋 5종은 그대로.
  • 다크 모드 — 종이 프리셋마다 별도 어두운 배색. 글자 대비는 전 조합 WCAG AA(4.5:1) 자동 테스트로 강제.
  • 줄공책 서체 — 실기기에서 손글씨체 4종을 차례로 써 보고 모두 탈락, 매직 포스터체 Do Hyeon(한 파일 880KB)으로 확정. 본문은 활자.
  • 결함 수정 — 테마 시트가 반만 열려 아랫부분이 내비게이션 바에 가리던 문제, 줄공책 목록에서 광고 카드가 괘선을 깨던 문제.
  • 변경 없음 — 데이터 구조·위젯·알림·다국어·권한. 업데이트해도 기존 기념일은 그대로 유지됩니다.

승인 후 진행 순서

  1. 출시 전 결정 2가지승인과 함께

    ① 광고: 실제 AdMob ID를 넣고 Play Console 광고 선언·데이터 안전을 갱신할지, 1.2.1처럼 광고 없이 낼지. ② AI 축하 멘트: 백엔드를 배포해 켤지, 이번엔 숨긴 채 낼지.

  2. Play 내부 테스트 트랙결정 당일

    App Bundle(versionCode 5) 업로드, 실장님 Google 계정을 테스터로 등록. Play 스토어에서 정식 업데이트로 받아 최종 확인 — 심사 없이 수 분.

  3. 프로덕션 승격최종 확인 후

    내부 테스트에 올린 것과 같은 번들을 그대로 프로덕션으로 승격(재빌드 없음) → 관리형 게시. 지난번 실측: 제출 → 게시 8일.
